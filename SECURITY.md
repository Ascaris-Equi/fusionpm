# Security Policy

## Reporting a vulnerability

If you discover a security issue, please do not open a public issue.

Contact:

```text
fusionpm@bayvaxbio.com
```

Please include:

- affected file or component
- steps to reproduce
- potential impact
- suggested fix, if available

## Sensitive data

Do not upload patient-identifiable data, private clinical data, credentials, API keys, or proprietary datasets to public issues, pull requests, or examples.

## Supported versions

The repository is currently maintained as a research preview. Security support is provided on a best-effort basis.
